Relative Units Violations Test Page

This page demonstrates both correct usage of relative units and common violations using absolute units.

Passing Elements (Using Relative Units)

Width: Percentage (80%)

This container uses width: 80% which is a relative unit. It will scale proportionally to its parent container.

Width: Viewport Width (90vw)

This container uses width: 90vw which is relative to the viewport width. It adapts to different screen sizes.

Font Size: Em Units (1.25em)

This section uses font-size: 1.25em which is relative to the parent's font size. Em units cascade and scale proportionally.

Font Size: Rem Units (1.125rem)

This section uses font-size: 1.125rem which is relative to the root font size. Rem units provide consistent scaling across the document.

Height: Viewport Height (20vh)

This container uses height: 20vh which is relative to the viewport height. This allows responsive vertical sizing based on screen size.

Mixed Relative Units

This container combines multiple relative units: width: 75%, min-width: 20em, max-width: 90vw, font-size: 1rem. All relative units work together for responsive design.

Violating Elements (Using Absolute Units)

VIOLATION: Width in Pixels

This container uses width: 320px which is an absolute unit. The fixed pixel width doesn't adapt to different screen sizes or user preferences.

VIOLATION: Max-Width in Pixels

While using percentage for width (80%), this container uses max-width: 450px. The pixel-based max-width limits responsiveness on larger screens.

VIOLATION: Min-Width in Pixels

This container uses min-width: 300px which is an absolute unit. Fixed minimum widths can cause horizontal scrolling on small screens.

VIOLATION: Height in Pixels

This container uses height: 150px which is an absolute unit. Fixed pixel heights don't adapt to content or screen size changes.

VIOLATION: Max-Height in Pixels

This container uses max-height: 180px. Absolute max-height can cause content overflow issues on different devices.

VIOLATION: Min-Height in Pixels

This container uses min-height: 120px which is an absolute unit. Fixed minimum heights don't scale well across different contexts.

VIOLATION: Font Size in Pixels

This text uses font-size: 18px which is an absolute unit. Pixel-based font sizes ignore user font size preferences and don't scale well.

VIOLATION: Line Height in Pixels

This text uses line-height: 24px which is an absolute unit. Absolute line heights don't scale proportionally with font size changes.

VIOLATION: Multiple Absolute Units

This container violates multiple properties: width: 400px, height: 200px, font-size: 16px, line-height: 22px. Multiple absolute units compound responsiveness issues.

VIOLATION: Point Units

This text uses font-size: 14pt which uses points, another absolute unit. Points are designed for print media, not responsive web design.

Nested Container Violations

Outer Container (Passing: width: 90%)

This outer container correctly uses percentage width.

VIOLATION: Inner Container (width: 280px)

This nested container violates the rule with width: 280px. Even when the parent uses relative units, children can still violate with absolute units.

VIOLATION: Another Inner Container

Multiple nested containers can each have their own violations. Each should be detected independently.

Inline Style Violations

VIOLATION: Inline Width Style

This container uses inline style="width: 350px". Inline styles with absolute units should also be detected as violations.

VIOLATION: Multiple Inline Properties

This uses inline style="height: 140px; font-size: 17px". Multiple absolute unit violations in inline styles.

Summary

This test page demonstrates the importance of using relative units for responsive design. The relative_units metric should detect all containers using absolute units (px, pt, cm, mm, in, pc) for width, height, font-size, and line-height properties.

Passing elements use relative units like %, em, rem, vw, vh, vmin, vmax, which adapt to different screen sizes, zoom levels, and user preferences.
