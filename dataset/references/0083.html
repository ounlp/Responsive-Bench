Mode : Auto-Reconnect to bluetooth device

by Taewook Yang (ワリ)

Version 2 ( January 2, 2018 )

Download flow file (184 downloads)

  1. Automate Community
  2. Personalization

Description

- This flow will help connect to selected bluetooth device automatically.
- For use it, target device must be once paired to main device manually.

This community flow is intended for users who want their Android device to reconnect to a previously paired Bluetooth device with less manual effort.

Before using the flow, make sure the target Bluetooth device has already been paired successfully at least once through the system Bluetooth settings.
