Line Spacing Violations Test Page

This page demonstrates both correct line spacing (>= 1.5) and violations (< 1.5). Line spacing affects readability, especially for users with dyslexia or other reading difficulties.

Passing Elements (Line Height >= 1.5)

Unitless 1.5 (Minimum)

This paragraph uses line-height: 1.5 which is the minimum acceptable value. This is a unitless number, which is the recommended way to specify line height in CSS. It multiplies the element's font size to determine the actual line height.

Unitless 1.8 (Comfortable)

This paragraph uses line-height: 1.8 which provides generous spacing. This makes text more readable, especially for longer paragraphs or users who need extra spacing for accessibility reasons.

Percentage (160%)

This uses line-height: 160% which equals 1.6. Percentage values are calculated relative to the element's font size.

Em Units (1.5em)

This uses line-height: 1.5em. Em units are relative to the element's font size, similar to percentages.

Double Spacing (2.0)

This paragraph uses line-height: 2.0 for extra generous spacing. This is particularly helpful for users with certain visual or cognitive disabilities. The large spacing makes each line very distinct.

Violating Elements (Line Height < 1.5)

VIOLATION: Unitless 1.2

This paragraph uses line-height: 1.2 which is below the minimum. Notice how the lines feel more cramped and harder to read, especially in longer paragraphs. This is a common default but fails accessibility guidelines.

VIOLATION: Single Spacing (1.0)

This paragraph uses line-height: 1.0 which means no extra spacing. The text is very cramped and difficult to read. Lines can appear to merge together, especially for users with visual impairments or reading difficulties.

VIOLATION: Percentage (130%)

This uses line-height: 130% which equals 1.3. While better than 1.0, it's still below the 1.5 minimum.

VIOLATION: Em Units (1.3em)

This uses line-height: 1.3em. The tight spacing makes longer text harder to parse.

VIOLATION: Pixel-Based (20px on 16px)

This uses font-size: 16px; line-height: 20px which gives a ratio of 1.25. Absolute pixel values for line-height can cause issues when font sizes change. The computed ratio is below the 1.5 minimum.

VIOLATION: Equal Font and Line Height

This uses font-size: 18px; line-height: 18px giving a ratio of 1.0. There is literally no extra vertical space between lines. This makes text very difficult to read and is particularly problematic for accessibility.

VIOLATION: Rem Units (1.25rem)

This uses font-size: 1rem; line-height: 1.25rem. While using relative units is good for other properties, this still violates the 1.5 line-height minimum.

VIOLATION: Inherited Tight Spacing

This child element inherits line-height: 1.1 from its parent. Inheritance of tight line-height can propagate violations throughout the DOM tree. Each element with text content should be checked.

VIOLATION: Override with !important

This uses line-height: 1.15 !important to override the base 1.8. Even with !important declarations, violations should be detected.

Headings - Common Violation Source

H1 Heading (line-height: 1.2) - VIOLATION

Headings commonly use tighter line-height for visual design, but they should still meet the 1.5 minimum for accessibility.

H2 Heading (line-height: 1.3) - VIOLATION

Even though headings are typically shorter, they should maintain adequate spacing.

H3 Heading (line-height: 1.4) - VIOLATION

Summary

This test page demonstrates the importance of adequate line spacing for readability and accessibility. The line_spacing metric should detect all elements with line-height < 1.5 (when computed as a ratio of font-size).

Passing elements use line-height values of 1.5 or greater using various CSS units: unitless numbers, percentages (>=150%), em units (>=1.5em), or pixel values that compute to >=1.5 ratio.
